# SPEC

## §G GOAL
desktop app (Linux + Windows) manage RimWorld profiles: create/clone/delete/rename/launch. ∀ profile isolates saves+config+log. profile ∈ {LIVE, OFFLINE}; OFFLINE = private frozen copies of active mods, immune to workshop updates/unsubs/new subs. avg-player UX. v1.1 GUI redesign: task-first (find profile → see state → play, fewest steps) + flows: first-run setup, Steam launch guide, read-only profile mod list, profile health check. profiles start from \| later take on another profile's game + mod settings by group ∴ new profile ⊥ empty. v1.2 game builds: profile pins a captured game build (key = `Version.txt`) \| Steam install ∴ switch 1.6↔1.7 ⊥ Steam redownload; same version ⇒ 1 shared copy. v1.3 RimWorld 1.7 (Waylith engine, R37): full parity w/ 1.6 on Linux + Windows — LIVE + OFFLINE, launch from app/Steam/RimSort, in-game Restart, 1.6 + 1.7 profiles side by side via game builds.
