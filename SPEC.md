# SPEC

## §G GOAL
desktop app (Linux + Windows) manage RimWorld profiles: create/clone/delete/rename/launch. ∀ profile isolates saves+config+log. profile ∈ {LIVE, OFFLINE}; OFFLINE = private frozen copies of active mods, immune to workshop updates/unsubs/new subs. avg-player UX. v1.1 GUI redesign: task-first (find profile → see state → play, fewest steps) + flows: first-run setup, Steam launch guide, read-only profile mod list, profile health check. profiles start from \| later take on another profile's game + mod settings by group ∴ new profile ⊥ empty.

## §I INTERFACES
- cmd: `rwpm run [--from rimsort] <profile-id> -- <game exe> [args…]` → builds env/args for profile mode + OS, spawns game, waits through in-game Restart (V17), exit code = spawned program's (first of `%command%` ∴ outermost wrapper when Steam wrappers precede game; game's own only w/o wrappers). `%command%`-compatible (Steam, RimSort). profile-id = stable profile dir name ≠ display name = slug of first name (`[a-z0-9-]`, ≤ 40, `-N` on collision, `default` reserved); ⊥ `=`, ⊥ whitespace. OFFLINE ∧ guard (V5) trips → small native dialog (Linux zenity, Windows PowerShell WinForms) before spawn: Add to profile (copy now) \| Turn off (drop from activeMods) \| Launch anyway \| Cancel (⊥ launch); dialog unavailable → launch + log to `<profile>/rwpm.log`. Linux OFFLINE: game argv[0] = rwpm; rwpm w/ env `RWPM_RESTART=<profile-id>` + `RWPM_GAME_EXE` + game args → restart mode: rebuild launch, exec game (⊥ lock, ⊥ guard).
- gui: iced app. profile list; New / Clone / Delete / Rename; LIVE↔OFFLINE toggle w/ progress; Refresh; Launch; Open log / Copy log for support; Export to RimSort; Remove from game folder; Settings (game path, Steam path, Profiles folder + Move).
- file: `<profile>/profile.toml` — `schema = 1`, `name` (display; Rename changes only this), `mode` (`live`|`offline`), `[[frozen_mods]]` {`folder`, `package_id`, `source` (`workshop`|`local`), `source_dir`, `copied_at` (TOML datetime)}. newer `schema` \| unknown field → error. Default profile has no dir & no file.
- file: `<app data>/settings.toml` — `schema = 1`, `profiles_root` (absolute; absent → default), `game_dir`, `steam_dir` (optional overrides for discovery), `setup_done` (bool; first-run setup finished). newer `schema` \| unknown field → error. `rwpm run` + gui read it.
- file: `<profile>/last-run.toml` — written by `rwpm run` ∀ launch attempt: `time`, `started_by` ∈ {steam, app, rimsort, other}, `outcome` ∈ {ok, refused, failed}, `reason`, `exit`. overwritten each run; tool folder only. `started_by` decided once at `rwpm run` start, before it changes its env; 1st match wins: env `RWPM_STARTED_BY=app` (GUI Play, also via `flatpak run --env`) → app; marker in RimSort `run_args` (written by export) → rimsort (pre-v1.1 exports fall through); `SteamGameId` \| `SteamAppId` set → steam; else other. `--rwpm-inner` hand-off + in-game Restart keep it. Default's record: `<profiles root>/default/last-run.toml` (list skips `default`). written when the game starts (`exit` absent) + again at exit; refused/failed at once. RimSort export writes `run --from rimsort`; re-export still finds pre-v1.1 entries. Windows Steam sets both (verified T28).
- dir: `<profile>/SaveData/` (game save root), `<profile>/Mods/` (OFFLINE only), `<profile>/Player.log`.
- dir: profiles root default — Linux `~/.local/share/<app>/profiles` (Flatpak Steam layout, V31: `~/.var/app/com.valvesoftware.Steam/data/<app>/profiles`), Windows `%LOCALAPPDATA%\<app>\profiles`, macOS `~/Library/Application Support/<app>/profiles` (layout always Standard, V44). `<app>` = `RimWorld Profile Manager`. Delete → OS recycle bin.
- file: game default save dir — Linux `~/.config/unity3d/Ludeon Studios/RimWorld by Ludeon Studios` (Flatpak Steam: `~/.var/app/com.valvesoftware.Steam/config/unity3d/…`), Windows `%USERPROFILE%\AppData\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios`, macOS `~/Library/Application Support/RimWorld` (⊥ `unity3d`/`Ludeon Studios` subpath, R16/R29 live-confirmed). Player.log (Default, ⊥ `-logFile`): macOS `~/Library/Logs/Ludeon Studios/RimWorld by Ludeon Studios/Player.log` (R32, distinct from the save dir).
- file: payload `Rwpm.Payload.dll` (net48, entry `Doorstop.Entrypoint.Start`, ⊥ game refs) + UnityDoorstop libs shipped beside app. channel: env `RWPM_MODS_DIR` (absent → no-op), optional `RWPM_PAYLOAD_LOG`.
- dir: launcher copy `<app data>/bin/{rwpm, payload/Rwpm.Payload.dll, doorstop/libdoorstop.so \| .dylib}` — Flatpak Steam (V31) ∨ AppImage (V38) ∨ macOS (V46, always, R30 Gatekeeper translocation); Steam launch line + RimSort run_args + Play name it
- file: RimSort `settings.json` `instances.<name>` — {game_folder, config_folder=`<profile>/SaveData/Config`, local_folder=`<profile>/Mods` \| `<install>/Mods` (LIVE), workshop_folder, run_args=`<rwpm> run <profile-id> -- %command%` (str), steam_client_integration=true, launch_via_steam_protocol=false}. location = platformdirs user_data_dir (RimSort d2454505), same on macOS (`~/Library/Application Support/RimSort/settings.json`, live-confirmed T45). macOS `game_folder`/`local_folder` name the `.app` bundle itself \| `<bundle>/Mods`, ⊥ the install's parent dir (T45, live RimSort settings.json).
